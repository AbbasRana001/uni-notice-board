# University Digital Notice Board

A static website built and deployed using a full CI/CD pipeline.

## Tech Stack
- HTML & CSS
- Parcel (bundler)
- Docker & nginx
- GitHub Actions (CI/CD)
- HTMLHint & Stylelint (linting)

## Live Pipeline
- HTMLHint linting
- Stylelint linting  
- Docker image build
- Docker Hub push
